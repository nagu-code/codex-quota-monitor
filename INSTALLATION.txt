Publisher: Nagu Corporate Private Limited
Support: hello@nagu.co
Product site: https://codex-tracker.nagu.co/

SYSTEM REQUIREMENTS

Windows 10/11 x64, internet access, a browser and an authorized ChatGPT account
with Codex access. There is no separate Nagu sign-in or subscription.

RECOMMENDED - MICROSOFT STORE

Open https://apps.microsoft.com/detail/9P3DRP9M57W6 and choose the Store download.
Windows manages installation and updates. The Store can take time to approve an
update; check the version shown there. Store certification applies to the Store
package, not the separately distributed unsigned EXE.

ALTERNATIVE - UNSIGNED EXE

1. Download Codex-Quota-Monitor-Setup-1.5.1-x64-Unsigned.exe only from the product
   website or https://github.com/nagu-code/codex-quota-monitor/releases/tag/v1.5.1.
2. Compare the entire SHA-256 from the website and release's SHA256SUMS.txt with:

   Get-FileHash -LiteralPath ".\Codex-Quota-Monitor-Setup-1.5.1-x64-Unsigned.exe" -Algorithm SHA256

3. Confirm the installer is unsigned:

   Get-AuthenticodeSignature -LiteralPath ".\Codex-Quota-Monitor-Setup-1.5.1-x64-Unsigned.exe" | Format-List Status

   Expected status: NotSigned. A checksum confirms matching bytes; it does not
   supply a publisher signature or guarantee that software is risk-free.
4. Open the verified EXE and follow its installer. SmartScreen or an Unknown
   publisher warning may appear. Proceed only if you intended to install this
   exact file and have verified it. Do not disable security controls or bypass
   an organization's policy. No certificate installation is required.

The current direct release has no ZIP distribution or certificate-trust scripts.
Older releases remain archived; their installation instructions apply only to
those older files.

SIGN IN AND REFRESH

Choose Add account, give it a label, and complete OpenAI's official browser flow.
Keep the app open for the localhost callback. Choose the correct browser account;
the app marks it connected only after identity and quota checks succeed.

Version 1.5.1 reloads an account's helper once if a successful browser login has
no active identity. Refresh all can retry a failed verification without asking
for another sign-in. Network failures preserve the latest successful readings.
Startup refreshes automatically; Refresh all resets the hourly refresh timer.
Fully quit using the tray's Quit action when restarting; closing the window can
leave the tray app running. Revoked access may still require a new sign-in.

LOCAL DATA AND LAN SHARING

Windows credentials are protected for the current user with DPAPI. The EXE
profile is %APPDATA%\codex-quota-monitor. The Store uses Windows package-managed
storage and a separate profile; accounts are not automatically imported between
editions. Do not upload account-home folders, tokens, cookies or profile backups.

While the app runs, its LAN dashboard on port 4319 exposes readings and Refresh
all to anyone who can reach the URL. It has no password or TLS. Use a trusted LAN;
credentials and account-management controls are not sent to viewers. Quit the
app to stop sharing.

UNINSTALL AND SUPPORT

Quit the app, then use Windows Settings > Apps > Installed apps > Uninstall.
Removing an account in the app deletes that monitor entry and its local saved
credentials, not the OpenAI account. For a clean EXE profile, back up or rename
%APPDATA%\codex-quota-monitor only after quitting and only when you intend to
reset local accounts and preferences. A backup contains sensitive data and must
remain private. Store removal follows Windows package-data handling.

For problems, send the on-screen error and app version to hello@nagu.co; never
send passwords, tokens or account-home files. Read the bundled LICENSE.txt,
PRIVACY.md and third-party notices. This product is independent of OpenAI.
