# Contributing

This is the public binary and documentation distribution repository for Codex
Quota Monitor. The application source code is proprietary and is maintained in
a separate private repository.

## Current contribution boundary

The project is not currently accepting pull requests. This includes source code,
reverse-engineered or decompiled material, modified binaries, installers,
repackaged releases, signing material, and unsolicited release-automation
changes. Do not upload credentials, account data, private logs, or third-party
confidential information.

Public issues may be used for reproducible product bugs, installation problems,
feature suggestions, and corrections to public documentation. Acceptance of an
issue does not promise a change, release, maintenance period, or delivery date.

Security vulnerabilities must be reported privately as described in
[SECURITY.md](SECURITY.md), not through a public issue.

## Useful public reports

For a non-security bug, include the released app version, Windows version,
distribution type, expected behavior, actual behavior, and minimal reproduction
steps. Redact email addresses, account names, file-system usernames, tokens,
cookies, `auth.json`, DPAPI vault data, and other sensitive information from
screenshots and logs.

Submitting an issue or suggestion does not change the proprietary license or
grant rights to the application's source code or branding.
